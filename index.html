Abstract

Overview

Large language models hallucinate, have limited context windows, and suffer from the "lost-in-the-middle" problem. Standard RAG returns text fragments without representing relationships between facts. GraphRAG fixes this.

GraphRAG Pipeline combines knowledge graph construction with retrieval-augmented generation. Instead of feeding raw text chunks to an LLM, the pipeline extracts a structured knowledge graph from documents, retrieves a compact evidence subgraph relevant to the question, and generates an answer with a reasoning trace backed by specific provenance records.

The system is evaluated against the MTRAG multi-turn conversational benchmark across four domains: ClapNQ, Cloud, FiQA, and Govt.

Knowledge Graph Construction

Extract entities, relations, and triples using kg-gen with entity resolution and alias normalization to produce a consistent, queryable knowledge graph.

Evidence Subgraph Retrieval

Retrieve compact, relevant subgraphs from the KG using hybrid/graph/corpus strategies with configurable triple scoring and pruning.

Provenance-Backed QA

Generate answers with explicit reasoning traces and structured evidence references, enabling verifiable, transparent results.

Architecture

Data Pipeline

The system uses a filter-style pipeline pattern. A shared PipelineContext flows through ordered steps, each reading from and writing back to the context. Every step is isolated in its own module with a clear contract.

Steps

Pipeline Steps

The default pipeline chains standardization through answering. Each step reads from and writes back to the shared PipelineContext.

1

KG Generation

Extract entities, relations, and triples from input text using kg-gen. Applies entity resolution and alias normalization to produce a consistent knowledge graph.

kg-gen · OpenAI / DeepSeek

2

Question Standardization

Normalize the user question via LLM rewrite and alias replacement against the KG. Links question entities to canonical KG entities for precise retrieval.

LLM Rewrite · Entity Linking

3

Subgraph Retrieval

Retrieve a compact evidence subgraph from the KG relevant to the normalized question. Supports hybrid, graph-only, and corpus-only strategies with configurable pruning.

Hybrid / Graph / Corpus · Triple Scoring

4

Answer Generation

Generate an answer with a reasoning trace backed by specific provenance records from the retrieved subgraph. Produces structured evidence references alongside the answer.

LLM Reasoning · Provenance References

5

Benchmark Evaluation

Run the pipeline against MTRAG benchmark tasks across four domains (ClapNQ, Cloud, FiQA, Govt) with configurable sampling, retrieval strategies, and LLM judge providers.

MTRAG · nDCG / Recall · LLM Judge

Setup

Getting Started

Install and configure the pipeline in a few steps.

Prerequisites

python -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -e '.[dev]'

Configuration

# .env
OPENAI_API_KEY=sk-...
DEEPSEEK_API_KEY=sk-...
MODEL_PROVIDER=openai
MODEL_NAME=gpt-4o-mini
Commands

CLI Usage

All commands are exposed through the graphrag CLI, built with Typer.

Build a Knowledge Graph

graphrag kg-build \
  --input path/to/file.txt

Extract entities, relations, and triples from a plain text file.

Build from MTRAG

graphrag kg-build-mtrag \
  --mtrag-root mt-rag-benchmark \
  --output-dir data/kg/mtrag_collections \
  --source-mode passage-corpus \
  --split-by-collection \
  --collection fiqa --collection govt \
  --max-passages-per-collection 500

Normalize a Question

graphrag normalize \
  --question "What is GraphRAG?" \
  --kg-dir data/kg/example

Retrieve Subgraph

graphrag retrieve \
  --question "What is GraphRAG?" \
  --kg-dir data/kg/example

Generate Answer

graphrag answer \
  --question "What is GraphRAG?" \
  --kg-dir data/kg/example

Full Pipeline

graphrag run \
  --question "What is GraphRAG?" \
  --kg-dir data/kg/example
